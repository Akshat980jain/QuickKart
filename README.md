QuickKart is a full-stack, enterprise-grade e-commerce platform designed for curated luxury shopping. Built with modern web technologies, responsive Material Design tokens, and native mobile compatibility, QuickKart delivers a seamless end-to-end commerce experience for customers, store administrators, and marketplace merchants.

---

## Key Platform Capabilities

### 🛒 Customer Discovery & Shopping Experience
* **Curated Catalog:** Browse products across refined categories with real-time search, price range filters, and star ratings.
* **Product Specification Matrix:** Side-by-side comparison table for evaluating product specifications, pricing, and warranties.
* **Flash Sales & Hot Deals:** Real-time countdown timer integration for seasonal offers and limited-time discounts.
* **Frictionless Checkout:** Multi-step shipping address validation, payment gateway choices (UPI, Cards, COD, NetBanking), and instant order confirmation.
* **Responsive Dark Mode:** Fluid light/dark theme adaptation built on custom HSL color tokens (`#00241a` Emerald & `#fd6c1a` Terracotta).

### 💎 Concierge, Support & Loyalty Ecosystem
* **QuickKart VIP Circle:** Points balance tracking, VIP tier progression (Bronze, Silver, Gold, Platinum), and voucher redemption catalog.
* **Digital Gift Cards:** Customizable digital e-vouchers with instant email delivery and custom occasion themes.
* **Self-Service Returns Portal:** Order lookup, return reason authorization, and instant printable RMA shipping labels.
* **Help Center & Store Locator:** Interactive FAQ knowledge base and boutique store locator with geolocation mapping.

### 🛠️ Executive Admin & Merchant Control Suite
* **Executive Analytics:** GMV metrics, Customer Lifetime Value (LTV), Conversion Rate tracking, and category sales velocity graphs.
* **Master Order Queue:** Centralized fulfillment queue with status management, invoice printing, and tracking assignment.
* **Promotions & Coupon Builder:** Custom coupon code creation, usage tracking, and discount rule controls.
* **Helpdesk Support Ticket Inbox:** Agent ticket management, SLA indicators, and priority routing.
* **Multi-Vendor Portal:** Seller onboarding, commission management, and merchant performance analytics.

---

## Tech Stack

* **Web Frontend:** React 18, TypeScript, Tailwind CSS, Lucide React, Vite
* **Mobile App:** Native Android (Kotlin), Material Design 3, Retrofit, Coroutines
* **Backend Microservices:** Node.js, Express.js, JWT Authentication, bcrypt
* **Database & Storage:** MongoDB Atlas, Mongoose ORM

---

## Quick Start

### Web Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### Backend API Setup
```bash
cd backend
npm install
npm run dev
```

### Android Mobile App
Open the `android` directory in Android Studio, sync Gradle dependencies, and launch on an emulator or physical device.
